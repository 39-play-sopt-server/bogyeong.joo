##  ✨ 브랜치 컨벤션

실습과 과제를 구분하여 아래 형식으로 브랜치를 생성합니다.

| 구분 | 브랜치 형식 | 예시 |
| --- | --- | --- |
| 🧑‍💻 실습 | `feat/{이슈 번호}/seminar{주차}` | `feat/1/seminar1` |
| 📝 과제 | `feat/{이슈 번호}/homework{주차}` | `feat/2/homework1` |

##  ✨ 커밋 컨벤션

커밋 메시지는 `타입: 커밋 메시지` 형식으로 작성합니다.

>  예시: `feat: 회원가입 기능 구현`

| 타입 | 사용 상황 |
| --- | --- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | README 등 문서 작성 및 수정 |
| `refactor` | 기능 변경 없이 코드 구조 개선 |
| `test` | 테스트 코드 추가 및 수정 |
| `chore` | 빌드 설정, 의존성 등 유지보수 작업 |
| `perf` | 성능 개선 |
| `ci` | CI/CD 설정 수정 |
| `revert` | 이전 커밋 되돌리기 |
